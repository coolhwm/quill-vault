# Issue tracker: GitHub

Specs and implementation tickets for this repository live as GitHub Issues in `coolhwm/quill-vault`.

## Conventions

- Use the connected GitHub integration for issue operations.
- Create specifications and implementation tickets in `coolhwm/quill-vault`.
- Apply the `ready-for-agent` label when the publishing skill requires it.
- Use native GitHub blocking relationships when available; otherwise include a `Blocked by` section containing issue references.
- Pull requests are not treated as a request surface.

## When a skill says “publish to the issue tracker”

Create a GitHub Issue in `coolhwm/quill-vault`.

## When a skill says “fetch the relevant ticket”

Read the referenced GitHub Issue and its comments.
