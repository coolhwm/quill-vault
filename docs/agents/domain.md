# Domain Docs

This is a single-context repository.

## Before exploring or changing the project

- Read `CONTEXT.md` at the repository root.
- Read relevant architectural decisions under `docs/adr/`.
- Use the canonical vocabulary from `CONTEXT.md` in specifications, tickets, code, and tests.
- Surface conflicts with existing ADRs instead of silently overriding them.

If a domain file does not yet exist, proceed without creating an empty placeholder. Use the domain-modeling workflow when a term or durable decision needs to be recorded.
