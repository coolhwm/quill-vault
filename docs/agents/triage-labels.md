# Triage Labels

The engineering skills use five canonical triage state roles. This file maps each role to the corresponding GitHub label in `coolhwm/quill-vault`.

| Label in Matt Pocock's skills | Label in this repository | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer needs to evaluate this issue |
| `needs-info` | `needs-info` | Waiting for the reporter to provide information |
| `ready-for-agent` | `ready-for-agent` | Fully specified and ready for an agent |
| `ready-for-human` | `ready-for-human` | Requires human implementation or judgment |
| `wontfix` | `wontfix` | Will not be actioned |

Every triaged issue should carry exactly one category label (`bug` or `enhancement`) and exactly one state label from this table.

When a skill mentions a canonical role, use the corresponding repository label from the middle column.
