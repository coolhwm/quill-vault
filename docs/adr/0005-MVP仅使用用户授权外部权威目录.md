# MVP 仅使用用户授权外部权威目录

Quillvault MVP 不申请应用自有 iCloud 容器，也不创建应用默认的 iCloud
Drive 权威目录。首次使用时，用户必须通过系统文件夹选择器显式授权一个
外部目录；该目录可以位于 iCloud Drive、Obsidian Vault、本机或其他 Files
Provider。授权成功后，该目录就是唯一权威目录，并通过安全作用域 URL、持久
书签和文件协调访问。授权缺失、被撤销或书签失效时，App 必须停止创建或写入
会议资产并引导用户重新选择，不能静默回退到 App 私有目录。

这个决定使 MVP 可以使用普通开发团队签名，并让所有会议资产从第一天起都由
用户明确选择存储位置。应用自有默认 iCloud 目录作为后续版本能力单独设计和
验收，不属于当前 MVP。
