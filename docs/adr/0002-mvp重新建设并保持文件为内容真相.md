# MVP 重新建设并保持文件为内容真相

Quillvault MVP 依据真机技术闭环 Demo 的验证结论重新建设为可长期演进的产品工程，不复用 Demo 的工程结构，也不将其渐进重构为正式版本。`recording.m4a`、`transcript.md` 与 `minutes.md` 继续构成用户可直接读取的内容真相；App 本地数据库只保存可从这些文件重建的检索索引，以及保证异步纪要任务可检查点恢复的运行状态。该选择牺牲了以私有数据库统一管理内容的实现便利，换取文件主权、外部工具兼容性、故障可恢复性和删除 App 后仍可使用的会议资产。
